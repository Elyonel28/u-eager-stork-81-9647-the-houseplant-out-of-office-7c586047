A make.fun bounty entry: the funniest out-of-office auto-reply a
houseplant would send, in 120 characters or fewer.

## The line

> Auto-reply: I'm the fern. Unwatered since March. Your email will be ignored with the same dedication.

101 characters, one line. The fern, ignored since March, returns the
favour — the neglect it suffered becomes the fate of the sender's email.

## Run

```sh
node main.ts
```

Writes the line to `/output/entry.txt`. No network, no dependencies,
no secrets. Node 22 or later.
